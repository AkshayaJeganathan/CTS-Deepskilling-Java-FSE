# Hands-On 6: Services & Dependency Injection

## Objective
Centralize shared application state and data access logic in the `student-course-portal` application using Angular Services and Dependency Injection (DI). Implement root-level singleton services (`CourseService`, `EnrollmentService`), demonstrate service-to-service injection, and explore component-level provider scoping (`NotificationService`).

## Topics Covered
- **Creating & Providing Services**: `@Injectable({ providedIn: 'root' })` singleton pattern vs component-level providers (`providers: [...]`).
- **Data Models**: Strong typing via TypeScript interface `Course` (`models/course.model.ts`).
- **Service as Shared Data Store**:
  - `CourseService`: Providing central course listings to `CourseListComponent`, `HomeComponent`, and `CourseSummaryWidgetComponent`.
  - `EnrollmentService`: Tracking enrolled course IDs and mapping them to `Course` objects.
- **Service-to-Service Injection**: Injecting `CourseService` into `EnrollmentService`.
- **Component-Level Scoped DI**: Providing `NotificationService` inside `NotificationComponent` to create an isolated service instance per component instance.

## Technologies Used
- Angular v17+ / v20.0
- TypeScript (Interfaces, Injectable)
- Angular Dependency Injection

## Running Instructions
1. Navigate to project:
   ```bash
   cd student-course-portal
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   ng serve
   ```

## Expected Output
- Home dashboard stats row displays the live course count (`5`) dynamically read from `CourseService`.
- Course List page renders `CourseSummaryWidgetComponent` showing total available courses; clicking "+ Add Sample Course" updates the count across all injected components simultaneously (confirming the singleton instance).
- Clicking "Enroll" / "Unenroll" on any course card toggles button label and state instantly via `EnrollmentService`.
- Navigating to the Profile page (`/profile`) displays the exact list of enrolled courses resolved by `EnrollmentService`.
- `NotificationComponent` renders its isolated alert with instance ID generated by component-level scoped `NotificationService`.
