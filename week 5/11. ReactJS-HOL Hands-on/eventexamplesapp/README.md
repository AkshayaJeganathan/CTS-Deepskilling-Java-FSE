
# ReactJS-HOL Hands-on 11

## Objective
Implement event handling concepts in React.

## Project Name
eventexamplesapp

## Features
- Increment and Decrement Counter
- Multiple method invocation
- Passing arguments to event handlers

- Currency Convertor (INR to EURO)

## Technologies Used
- React
- JavaScript ES6
- Node.js
- npm

## Run
