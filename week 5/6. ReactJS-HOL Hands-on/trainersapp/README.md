# ReactJS Hands-on 6 – React Router

## Objective

This hands-on demonstrates the implementation of React Router for navigation in a Single Page Application (SPA).

## Technologies Used

- ReactJS
- React Router DOM
- JavaScript (ES6)
- Node.js
- NPM
- Visual Studio Code

## Features

- Home Page
- Trainer List
- Trainer Details
- Navigation using React Router
- URL Parameter Passing using useParams
- Mock Trainer Data

## Components

- Home
- TrainersList
- TrainerDetails
- Trainer
- TrainersMock

## Routing

| URL | Component |
|------|-----------|
| / | Redirects to Home |
| /home | Home |
| /trainers | Trainers List |
| /trainer/:id | Trainer Details |

## How to Run

```bash
npm install
npm start
```

Open:

```
http://localhost:3000
```

## Output

- Home Page
- Trainers List
- Trainer Details
- React Router Navigation
