# ReactJS-HOL Hands-on 9

## Objective
Implement ES6 features in React including:
- map()
- filter()
- Arrow Functions
- Destructuring
- Spread Operator

## Project Name
cricketapp

## Features
- Display list of 11 cricket players
- Filter players scoring below 70
- Display odd and even team players
- Merge T20 and Ranji Trophy players using spread operator
- Conditional rendering using a flag

## Technologies Used
- React
- JavaScript ES6
- Node.js
- npm

## Run the Project

```bash
npm install
npm start
```
