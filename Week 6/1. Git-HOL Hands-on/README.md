# Git Hands-on 1

## Objective
Practice the basic Git workflow by configuring Git, initializing a repository, tracking files, and creating commits.

## Tools Used
- Git
- Git Bash / Command Prompt
- Visual Studio Code / Notepad

## Tasks Performed
- Configured Git username and email.
- Configured the default Git editor.
- Created a local Git repository.
- Initialized the repository using `git init`.
- Created a sample file `welcome.txt`.
- Checked repository status using `git status`.
- Added the file to the staging area using `git add`.
- Committed the file using `git commit`.
- Verified Git configuration.

## Commands Practiced
- `git --version`
- `git config --global user.name`
- `git config --global user.email`
- `git config --global core.editor`
- `git config --list`
- `git init`
- `git status`
- `git add`
- `git commit`
- `git pull`
- `git push`
