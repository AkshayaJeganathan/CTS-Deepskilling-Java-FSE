# Git HOL 3 – Branching and Merging

## Objective
This hands-on demonstrates Git branching and merging operations.

## Tasks Performed
- Created a new branch `GitNewBranch`
- Switched to the new branch
- Created `branch.txt`
- Committed changes to the branch
- Switched back to `master`
- Compared branches using `git diff` and `git difftool`
- Merged `GitNewBranch` into `master`
- Verified commit history using `git log --oneline --graph --decorate`
- Deleted the merged branch
- Verified repository status

## Git Commands Used
- git branch
- git checkout
- git status
- git add
- git commit
- git diff
- git difftool
- git merge
- git log
- git branch -d
