# Git Hands-on 2

## Objective

Learn how to use the `.gitignore` file to exclude unwanted files and folders from Git version control.

## Tools Used

- Git
- Command Prompt / Git Bash
- Notepad

## Tasks Performed

- Initialized a Git repository.
- Created sample files and folders.
- Created a `.gitignore` file.
- Ignored all `.log` files.
- Ignored the `logs` directory.
- Verified ignored files using `git status`.
- Committed the tracked files.

## Files Ignored

- `*.log`
- `logs/`

## Commands Practiced

- `git init`
- `git status`
- `git add`
- `git commit`
- `.gitignore`

## Outcome

Successfully implemented `.gitignore` to prevent unwanted log files and log folders from being tracked by Git.
